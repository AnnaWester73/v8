# E2E-tester för Timer Vue

## Projektet ska betrakta:
* https://lejonmanen.github.io/timer-vue/ 

### Skapa User stories:
* skapa och ta bort widgets - timer och anteckning
* byta plats på två widgets
* ändra tidsinställning på timer
* starta, pausa, återställ
* ändra texten för anteckning
* ändra temafärg

## Dokumentation
* User stories docs/user_stories.md
* Acceptanskriterier docs/acceptence_criteria.md
* Testscenarier docs/test_scenarios.md
